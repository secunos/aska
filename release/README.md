# Release signing

`aska-release.pub` is the project's minisign public key. It is embedded in every release
build (`ASKA_RELEASE_PUBKEY`, see `scripts/release.sh`) so that `aska verify` can check the
signed hash list shipped next to the binaries, and it is published with every release so
that users can verify the tarball with `minisign -V -p aska-release.pub -m <file>`.

The secret key is held by the release owner only — never in the repository, never in CI,
never in the build container. Signing happens on the owner's machine:
`ASKA_RELEASE_SECKEY=~/.minisign/aska-release.key scripts/release.sh <tag> --sign`.
