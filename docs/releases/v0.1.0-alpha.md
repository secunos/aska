## Deviations recorded

1. **Toolchain:** built with `rustc 1.98.1`, not the intended 1.95.0 — `rust-toolchain.toml`
   said `stable`, which is not a pin. Fixed after the tag: `channel = "1.95.0"`, and
   `release.sh` refuses a different `rustc`.
2. **Build metadata:** `RELEASE-NOTES.txt` has an empty commit and `SOURCE_DATE_EPOCH`, and the
   tarball's entries carry a nonsensical mtime — `git` was absent on the build machine and the
   script carried on. Fixed after the tag: `release.sh` requires git, a checkout, and a numeric
   epoch; `package-gui.sh` falls back to epoch 0, never garbage. The content of the tarball is
   unaffected (hashes above are of the files, not the archive metadata).
3. **Cross-machine reproducibility:** the owner's binaries differ from the developer's for the
   same commit (different glibc linked into the static binaries, different compiler, different
   build paths). `REPRODUCIBLE: OK` states determinism on one machine; equality across machines
   requires the shared release container. Build-path remapping extended after the tag
   (`--remap-path-prefix` for the Cargo registry and the home directory).
4. **Not built in the Debian 13 container** (no container runtime on either build machine at
   the time); the GUI is linked against Ubuntu 26.04's GTK and glibc 2.43 and may not start on
   Debian 13 / Tails 7 — a packaging limitation of this alpha, not of the design.

The next release is cut with the fixed scripts from the release container.
