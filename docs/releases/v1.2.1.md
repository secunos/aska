## What changed since 1.2.0

1. **The icon.** `org.aska.Aska` is now the Glow mark on its dark rounded tile: the freedesktop `hicolor` theme ships PNGs from 16 to 512 px, the scalable SVG and a symbolic SVG (`deploy/gui/icons/hicolor/`); `install.sh` installs every size and refreshes the icon cache; the User Guide's removal command (§13) covers them.
2. **The palette.** The graphical client loads the "Nordic calm" colours as libadwaita colour overrides — ash greys with one ember accent — in a light and a dark set, swapped with the system's light/dark preference (`crates/aska-gui/brand/aska.css`, `aska-dark.css`; `crates/aska-gui/src/ui/brand.rs`). Every text colour meets WCAG AA against its background. The client's own rules load after the palette and refer to its colours.
3. **The lockup and the slogan.** The Home screen's title and tagline — the `title-1` label "Aska" and the line "Nothing is stored here. Ever." — are replaced by the full horizontal lockup: mark, wordmark and the slogan **Notes that leave no trace**, set in the kit's own typeface as outlines. It is drawn by a small fixed-height widget (84 px, the height of the two lines it replaces) from embedded images, one for light and one for dark, scaled so that the wordmark is the same size in both schemes (the on-dark image's glow overflows into the margins), so that the buttons below keep their positions — the coordinate-driven GUI gates pass unchanged. For assistive technology the widget is labelled "Aska — Notes that leave no trace" (Swedish: "Aska — Anteckningar som inte lämnar några spår"). The slogan also replaces the earlier tagline wherever it was written: the launcher entry's description (`org.aska.Aska.desktop`), the CLI's `--help` headline, and the texts (`app.tagline` in both locales).
4. **The repository.** The lockup at the top of the README (light/dark aware); `docs/brand/README.md` with the colour table and the usage rules. The wordmark is outlines (Outfit, SIL Open Font License); no font is installed or needed.

Nothing is read from disk at run time for any of this: the colour sheets and the lockup images are compiled into the binary. The window title remains `aska` on every screen (Client Design §5.7). `aska --version` → 1.2.1.

**Compatibility.** Identical to 1.2.0 in everything but appearance; notes, keys, Receiving Keys, pad pages, cards and profiles are unaffected; the relay is unchanged (operators need not upgrade; `aska-drop` 1.2.1 is a rebuild).
